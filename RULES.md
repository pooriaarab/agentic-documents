# agentic-documents rules

These rules bind every agent that edits a document with this package.

1. Label your work. Pass your real author kind and name on every change.
2. Read before you write. Read the outline and the section first.
3. Never guess a match. On an ambiguous match, choose an occurrence from the contexts.
4. Respect stale anchors. A stale anchor means the text changed. Read again.
5. Report failures as failures. No silent success follows a failed call.
6. Keep content out of logs. The edit log holds counts, not text.
